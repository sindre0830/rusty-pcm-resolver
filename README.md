# template-rust-crate

A minimal template repository for Rust projects.

## Setup

Install Rust and Cargo by following the [official guide](https://www.rust-lang.org/learn/get-started)


Build the project:

```bash
cargo build
```

Run the project:

```bash
cargo run
```

Run tests:

```bash
cargo test
```

### Manage Dependencies

Add a new crate:

```bash
cargo add <crate-name>
```

Update all crates:

```bash
cargo update
```

Build an optimized release:

```bash
cargo build --release
```
